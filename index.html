Frequently Asked Questions

Simple answers about how GRID protects your property

How does GRID connect to my building's hardware?
+
GRID uses compact 32-bit Xtensa and RISC-V microcontrollers (ESP32 / ESP8266) connected to non-invasive flow meters, current clamps, and climate probes. They clip onto your existing lines and stream live data over Wi-Fi.
What happens if the Wi-Fi briefly disconnects?
+
Our microcontrollers run non-blocking asynchronous code so sensor monitoring never pauses while reconnecting. Our cloud dashboard also pairs live WebSockets with automatic backup polling so you never miss an alert.
How does it know the difference between a shower and a pipe leak?
+
Instead of basic alarms, GRID learns your building's normal daily usage patterns. It easily tells apart normal daytime water use from a continuous hidden trickle inside a wall at 3:00 AM.
Can I test the live dashboard before installing sensors?
+
Yes! You can open the Dashboard tab right now or send test JSON readings to the /api/telemetry endpoint to watch the charts and alerts respond live.
